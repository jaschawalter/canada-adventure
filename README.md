# Canada Adventure 4.0 — Class 9

## GitHub Pages

Upload all three files **into the repository root** (the same directory):

- `index.html`
- `canada-illustrated-map.webp` — wide map illustration
- `canada-map-mobile.webp` — lightweight narrow-screen illustration

GitHub: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

Site: https://jaschawalter.github.io/canada-adventure/

## What changed in v4

- A **clean landscape without text or baked-in buttons** replaces the older artwork.
- Full 16:9 image-space with live, anchored buttons on larger screens.
- A two-column touch-friendly station list on small screens and portrait tablets.
- Clear completed states and Final Boss gating are preserved.
- Compact header/progress information and responsive games.
- The game state lives in memory only: reloading clears all progress.

## Important

Do not upload the ZIP itself to GitHub. Extract and upload the three files. The existing QR code URL does not change. iPhone/iPad physical touch tests are still recommended.
